# Lernapp: Lernen unter Prüfungsdruck

Webapp für Lernende (Schüler, Azubis, Studierende) zur Frage „Wie lerne ich unter Prüfungsdruck?“.
Schulprojekt im Fach Berufsbildende Projekte (BbP).

**Link:** https://vikrdn.github.io/Lernapp/

## Was die App kann
Prüfungs-Countdown mit Lernplan, Lerntyp-Test mit Tipps, Lernmittel (Notizen, Bilder, PDFs, Links), Lernkarten mit Quiz und Archiv,
Ziele und Reflexion, Fokus-Timer, Kalender-Export, Nachschlagen bei Wikipedia, Backup und Lernpakete zum Teilen.

## Datenschutz
Alle Daten bleiben im Browser auf dem eigenen Gerät. Es gibt keine Konten und keinen Server. Nur beim Nachschlagen wird der Suchbegriff an Wikipedia gesendet.
